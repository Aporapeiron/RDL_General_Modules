# 応用例：社会モデル Layering Profile v0.1

*RDL_General_Modules / Layering / Example*

## 0. 目的

社会構造を、更新速度・拘束範囲・沈降時間の異なる複数Layerとして整理する。

このProfileでは、

```text
Purpose = 社会構造と変化の伝播を整理する
Axis    = 更新速度 / 拘束範囲 / 沈降時間
```

を採用する。

---

## 1. 基本配置

```text
Geography
    ↓
History / Culture
    ↓
Institution
    ↓
Group / Organization
    ↓
Individual
    ↓
Realtime Events

変化しにくい
        ↓
変化しやすい
```

これは社会の普遍的な固定階層ではなく、現在のPurposeに対する有限な整理Profileである。

---

## 2. Geography Layer

地形・地理・気候・資源配置など、社会活動の可能域を長期間拘束する基盤条件。

例：

```text
山脈 / 河川 / 海岸
気候
天然資源
交通可能性
農業可能域
人口集中可能域
```

地理そのものを社会的 `M_B` と同一視する必要はない。

むしろ、後続する社会構造が取りうる可能域を強く拘束する低速条件として扱う。

---

## 3. History / Culture Layer

長期間の反復と世代継承によって沈降した関係構造。

例：

```text
言語
宗教
慣習
権威観
家族構造
歴史認識
集団間の記憶
交易・戦争の蓄積
```

一つの政権交代や短期政策では変化しにくいが、固定ではない。

---

## 4. Institution Layer

現在の社会を比較的明示的に拘束する制度構造。

例：

```text
憲法
法律
税制
行政制度
教育制度
市場制度
選挙制度
軍事・警察制度
```

History / Cultureより変更可能性は高いが、個人や一時的出来事よりは低速である。

---

## 5. Group / Organization Layer

制度と個人の間で実際の行動や関係を媒介する組織Layer。

例：

```text
企業
政党
官僚組織
学校
家族
地域共同体
宗教組織
オンラインコミュニティ
```

同じ制度下でも、組織ごとの履歴・局所規範・関係配置によって異なる有限構造が形成される。

---

## 6. Individual Layer

個人が保持する比較的高速な関係拘束。

例：

```text
経験
価値判断
人間関係
職業
経済状態
現在の目的
所属集団との関係
```

同一制度・同一文化に属していても、個人ごとの `M_B` は一致しない。

---

## 7. Realtime Event Layer

最も高速に変化する現在入力。

例：

```text
選挙
災害
価格急騰
戦争開始
政策発表
スキャンダル
SNS上の急速な話題拡散
```

これらは一回発生しただけで社会全体の低速Layerを書き換えるとは限らない。

---

## 8. 低速拘束と高速沈降

低速Layerから高速Layerへは、

```text
Geography
    ↓
History / Culture
    ↓
Institution
    ↓
Group
    ↓
Individual
    ↓
Realtime Action
```

という拘束伝播を考えられる。

一方、高速側の反復は、

```text
Realtime Event
    ↓ 反復
Individual / Group
    ↓ 定着
Institution
    ↓ 長期継続
History / Culture
```

のように低速Layerへ沈降しうる。

したがって、社会Layerは単純な一方向階層ではない。

---

## 9. B依存性

同じ対象でもBによってLayer配置は変わる。

例えば「法律」は、

```text
B = 現行行政運用
-> 比較的低速な制度Layer

B = 数百年規模の法制史
-> 変化する中間Layer

B = 今日の裁判・行政判断
-> 高速な現在運用Layer
```

と異なる位置を取れる。

```text
Layer_(B1)(x) != Layer_(B2)(x)
```

は矛盾ではない。

---

## 10. ξ と実体化防止

このProfileを用いて社会を綺麗に整理できても、

```text
Geography -> Culture -> Institution -> Group -> Individual
```

という階段構造そのものを社会の実体へ昇格させない。

実際の関係はLayer間を横断し、逆向き作用・直接作用・未回収関係を含む。

```text
Complete_B(Social Layer Map) = true
and
ξ(B) != 0
```

---

## 11. 一文圧縮

> **社会Layeringは、地理・歴史文化・制度・組織・個人・現在事象を、更新速度と拘束範囲の異なる有限Layerとして整理し、低速Layerからの拘束と高速Layerからの沈降を同時に記述する。**
